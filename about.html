ABOUT THE GAME

Built for the thrill of one more run

Night Rush 3D is an independent browser-based arcade racing project. The current version features a neon highway, stylized 3D cars, traffic, coins, nitro and a local high-score system.

The game is intentionally lightweight: it uses browser WebGL and does not require a separate app download, registration or a game account.

What kind of racing game is this?

It is an endless traffic-dodging arcade racer, not a realistic driving simulator or a lap-based motorsport title. Players move between lanes, collect bonuses and try to survive longer.

What is coming next?

Planned improvements include a wider selection of environments, more vehicle customization, clearer visual effects, additional gameplay objectives and deeper progression. These are roadmap ideas, not available features.
